# 智联招聘 URL 参考

本文记录智联招聘页面的 URL 格式、城市代码和搜索参数，仅用于人工浏览参考。禁止用于自动抓取或批量请求。

## 根域名

```
https://www.zhaopin.com
```

## URL 模式

### 搜索页

```
https://www.zhaopin.com/sou/?kw={关键词}&city={城市代码}&p={页码}
```

参数说明：

| 参数 | 说明 | 示例 |
|------|------|------|
| kw | 搜索关键词，URL 编码 | `%E4%BA%A7%E5%93%81%E7%BB%8F%E7%90%86`（产品经理） |
| city | 城市代码 | `654`（丽水）、`653`（杭州） |
| p | 页码，从 1 开始 | `1`、`2`、`3` |

完整示例：

```
https://www.zhaopin.com/sou/?kw=%E4%BA%A7%E5%93%81%E7%BB%8F%E7%90%86&city=654&p=1
```

### 职位详情页

```
https://www.zhaopin.com/jobdetail/{职位ID}.htm
```

职位 ID 格式：`CC` + 数字字母混合 + `J` + 数字，如：

```
https://www.zhaopin.com/jobdetail/CC123456789J40000000000.htm
```

`normalize_manual_job.py` 会自动从 URL 中提取职位 ID 作为去重键。如果 URL 不含标准 ID 格式，则回退到内容哈希。

### 公司详情页

```
https://www.zhaopin.com/companydetail/{公司ID}.htm
```

## 页面结构参考

> 以下为过往观察的智联详情页字段布局（可能随平台更新变化，仅作人工识别参考）。

典型的职位详情页可见文本布局：

```
职位名称          ← title
公司名称          ← company
工作地点          ← location
薪资范围          ← salary
工作经验          ← experience
学历要求          ← education
职位标签          ← tags
发布日期          ← date
职位描述          ← description（多行文本）
```

`normalize_manual_job.py` 按标签键值对解析，与页面实际布局顺序无关。粘贴时只需确保字段标签和值在同一行，用中文冒号或英文冒号分隔即可。

## 反爬与风控提示

- 智联招聘对高频搜索和异常 User-Agent 有风控机制。
- 正常人工浏览频率（每分钟 1-3 次搜索）一般不会触发验证码。
- 如遇到滑块验证码或登录墙，**立即停止操作**，等待冷却后重新手动浏览。
- 本项目不涉及任何反爬绕过手段。
